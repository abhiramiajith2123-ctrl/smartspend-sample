# SmartSpend AI – Sample Project

A mini full-stack Expense Tracker prototype built with **Python Flask**, **SQLite**, and **Bootstrap 5** for the BCA Final Year Project: *SmartSpend AI – An Intelligent Personal Financial Planning System*.

## Features
- Separate forms to add **Income** and **Expense** transactions
- Live **Recent Transactions** table with Delete functionality
- Real-time calculation of **Total Income**, **Total Expense**, and **Remaining Balance**

## How to Run Locally
1. Install Flask: `pip install flask`
2. Run the app: `python app.py`
3. Open `http://127.0.0.1:5000` in your browser
